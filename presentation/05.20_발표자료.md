# 05.20 음성 발표자료

# 1. 이번주 진행 사항

---

### 1-1. Wake Word 감지 모듈 구현 (`KWS/kws.py`)

- faster-whisper tiny 모델 기반 웨이크 워드("피식아") 감지 모듈 구현
- 인식 텍스트에 웨이크 워드가 포함되는지 exact match → Levenshtein fuzzy match 순서로 판단
- 모델을 매 호출마다 재로드하지 않도록 싱글톤 패턴 적용 (첫 호출 시 1회만 로드)
- 입출력 계약: `float32 numpy, mono, 16kHz` — 기존 파이프라인 모듈과 동일한 인터페이스 유지

### 1-2. KWS 단독 테스트 스크립트 작성 (`KWS/kws_test.py`)

- `data/` 폴더 전체 또는 단일 파일을 입력으로 웨이크 워드 감지 여부 출력
- exact match / fuzzy match 유사도 로그 함께 출력하여 임계값 튜닝에 활용 가능

### 1-3. 전체 파이프라인에 KWS 단계 통합 (`pipeline/pipeline.py`)

- 오디오 입력 → DeepFilterNet → **KWS** → VAD → Whisper STT → Command Parser → Task ID 흐름으로 통합
- 웨이크 워드 미감지 시 VAD·STT 등 후속 연산 없이 즉시 종료 (`WAKE_WORD_NOT_DETECTED` 반환)
- `--skip_kws` 플래그로 KWS 우회 가능 (평가·디버깅용)

**실행 방법**

```bash
# KWS 단독 테스트
python3 KWS/kws_test.py

# 전체 파이프라인 실행 (웨이크 워드 감지 포함)
python3 pipeline/pipeline.py --audio data/Red_noisy.m4a

# KWS 우회 실행 (평가용)
python3 pipeline/pipeline.py --audio data/Red_noisy.m4a --skip_kws
```

### 1-4. KWS 설정값 config.py 통합

- `WAKE_WORD = "피식아"`, `KWS_MODEL_SIZE = "tiny"`, `KWS_THRESHOLD = 0.6` 추가
- 기존 모듈과 동일하게 `Whisper/config.py`에서 중앙 관리

# 2. 이번 주 발생 이슈 및 해결

---

### 2-1. Whisper tiny 모델의 웨이크 워드 오인식

**현상**

"피식아" 발화 시 Whisper tiny가 "피시가", "피시카" 등 유사 발음으로 인식하여 exact match 실패

**원인**

tiny 모델은 파라미터 수가 적어 짧은 단어·고유 명사에 대한 인식 정확도가 낮음. 특히 한국어 고유 단어의 경우 학습 데이터 부족으로 오인식 빈도가 높음

**해결**

exact match 실패 시 Levenshtein 편집거리 기반 fuzzy match 로 폴백. 슬라이딩 윈도우로 텍스트 부분 문자열과의 최대 유사도를 계산하여 임계값(0.6) 이상이면 감지 성공으로 처리

# 4. 음성 명령 파이프라인 구성 및 진행 현황

---

음성 명령 파이프라인은 총 7단계로 구성되며, 현재 약 **75% 진행 중**.

### 단계별 구성 요약 (파이프라인)

| 단계 | 모듈 | 설명 | 상태 |
|------|------|------|------|
| 1단계 | 음성 입력 | 실시간 마이크 스트리밍 | 미완 |
| 2단계 | DeepFilterNet | 신경망 기반 노이즈 제거 | **오류 개선 중** |
| 3단계 | Wake Word | 특정 단어 감지 시 시스템 활성화 | **완료** |
| 4단계 | Silero VAD | 발화 구간만 추출, 묵음 제거 | 완료 |
| 5단계 | Whisper STT | 정제된 음성 → 텍스트 변환 | 완료 |
| 6단계 | Command Parser | 텍스트 → 명령어 ID 변환 | 완료 |
| 7단계 | Task ID 전달 | Task ID → 로봇 전달 | 부분 완료 |

전체 과정 중 약 **75% 달성** (3·4·5·6단계 완료 / 2·7단계 부분 완료 / 1단계 미완)

### 진행 사항 요약

- 완료: 3·4·5·6단계
- 부분 완료: 2단계 (DeepFilterNet — 오류 개선 중), 7단계 (Task ID 전달)
- 미완: 1단계 (실시간 마이크 입력)
- 다음 주 예정: 1단계 실시간 마이크 입력 구현, DeepFilterNet 오류 수정 및 소음 환경 데이터 재검증
- 이번 주 산출물: KWS 모듈 구현, 전체 파이프라인 KWS 단계 통합
